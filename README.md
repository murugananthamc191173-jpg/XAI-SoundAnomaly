For industrial applications, it is important to automatically detect anomalies in audio signals. The MIMII dataset consists of recordings collected from Japanese factories, including regular and abnormal sounds across various signal-to-noise ratio (SNR) conditions. This research focuses on the dataset under challenging -6 dB SNR conditions. Initially, both temporal and spectral handcrafted features were examined using traditional machine learning classifiers. The XGBoost classifier achieved 88% initial accuracy but failed to detect anomalies, revealing severe class imbalance. Transfer learning using the pretrained YAMNet model enhanced classification performance; however, anomaly recall remained low. To resolve this, a Denoising Diffusion Probabilistic Model (DDPM) was implemented for audio-space data augmentation, systematically adding Gaussian noise in a forward process and removing it in a reverse denoising process to synthesize realistic anomalous samples and rebalance the class distribution. Deep YAMNet embeddings were combined with handcrafted descriptors to build hybrid representations. Using bio-inspired metaheuristic feature selection algorithms Zebra Optimization Algorithm (ZOA), Whale Optimization Algorithm (WOA), Harris Hawks Optimization (HHO), and Particle Swarm Optimization (PSO) the high-dimensional feature space was refined. The ZOA-selected hybrid features evaluated with XGBoost achieved an optimum classification accuracy of 99.4% and 99\% recall. To ensure interpretability, SHAP and LIME frameworks were integrated to quantify and visualize feature contributions for diagnostic reliability and transparency. This framework provides a robust and explainable approach for industrial acoustic anomaly detection in noisy environments.
